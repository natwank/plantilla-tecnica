# Carpeta interna de la plantilla

Todo lo que hay aquí pertenece a la plantilla, no al proyecto que la usa. Su presencia es la
señal de que el repositorio todavía no está inicializado: `/empezar` la borra al final.

- `DECISIONES.md`: por qué la plantilla es como es.
- `changelog/`: historial de la plantilla. Mientras exista esta carpeta, los cambios sobre el
  andamiaje (AGENTS.md, skills, hooks, docs vacíos) se registran aquí, con el formato de
  `changelog/README.md`.
